## 📌 Project Overview

**Hashtag Daily** is a feature-rich blogging platform that allows users to create, share, and discover engaging content. Built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js), it provides a seamless experience for both content creators and readers.

Whether you're a blogger looking to share your thoughts or a reader seeking daily insights, Hashtag Daily offers a clean, responsive, and intuitive platform for all.

---

## ✨ Key Features

### 🔐 Authentication & Security
- JWT-based secure authentication
- User registration & login
- Protected routes and API endpoints
- Password encryption with bcrypt

### 📝 Blog Management
- Create, Read, Update, Delete (CRUD) blog posts
- Rich text editor for formatting content
- Image upload support for blog covers
- Category & tag management
- Draft & publish system

### 👥 User Features
- Personalized user dashboard
- Profile management with avatar upload
- View your own posts
- Like and comment on blog posts
- Save favorite articles

### 🎨 UI/UX
- Fully responsive design (Mobile, Tablet, Desktop)
- Modern and clean interface
- Dark/Light mode toggle
- Smooth animations and transitions
- Loader and skeleton screens

### 🚀 Performance
- Server-side pagination for fast loading
- Optimized MongoDB queries
- Image optimization and lazy loading
- Debounced search functionality
